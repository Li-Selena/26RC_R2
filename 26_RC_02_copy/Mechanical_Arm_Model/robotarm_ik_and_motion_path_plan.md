# 机械臂逆解和运动路径规划

## Summary

- 本文档记录机械臂内部逆解算与后续运动路径规划的设计计划。
- 当前只完整记录逆解部分；运动路径规划部分先作为待补充章节，等轨迹要求继续明确后再完善。
- 逆解先作为固件内部算法能力实现，不同步变更现有 USB/上位机 4-float 命令。
- 工具姿态、工具位置、吸盘/夹爪开启关闭等需要新的工具控制链，后续单独设计。

## 逆解算计划

### 输入与输出

- 内部 IK 输入：
  - 工具对象 `tool`
  - 工具几何状态 `tool_state`
  - 工具作用点目标三维坐标 `target_xyz_mm`
  - 当前方向 `current_direction`
  - 当前关节角 `current_theta_rad`
  - 当前长段连杆角 `current_alpha_rad`
- `target_xyz_mm.x/y` 只用于选择机械臂 yaw 工作方向；实际平面位移由底盘完成。
- 真正参与机械臂高度解算的是工具作用点的 `target_xyz_mm.z`。
- IK 输出：
  - 相对解算模型零位的实际关节角 `theta1/theta2/theta3`
  - 目标工作方向
  - 长段连杆角 `alpha`
  - J2/J3/J4/工具作用点世界坐标
  - 状态与失败原因
- IK 输出不包含电机零位偏置、输出轴方向或减速比映射；这些属于后续电机映射层。

### 零位定义

- 电机零位/编码器零位：实际上电凹型姿态，长段连杆朝 `-Y0` 且下倾 `6°`。
- 解算模型零位/IK 零位：
  - J2-J3 实际转动关节连线保持竖直。
  - 坐标系 4 与机械臂/J0 坐标系平行。
- IK 先在解算模型零位下输出关节角，再由后续映射层转换为真实电机命令。

### 方向选择

- 机械臂正常工作方向只有三个：
  - `Y+`
  - `X+`
  - `X-`
- yaw 角定义：
  - `Y+ => theta1 = 0`
  - `X+ => theta1 = -pi/2`
  - `X- => theta1 = +pi/2`
- 目标落在 `-Y` 区域时不分配到 `Y+`，按 `x` 正负选择 `X+ / X-`。
- 目标在 `-Y` 附近且 `x≈0` 时，保持当前 `X+ / X-`；若当前不是 X 方向，默认 `X+`。
- 三个方向切换只允许 J1 在 `[-pi/2, +pi/2]` 内转动，且以 `Y+` 为 `0`。
- yaw 方向切换时，底盘朝向不改变。

### 凸型连杆几何

- J2-J3 之间的物理连杆是刚性弯折连杆，不是额外关节。
- 几何参数：
  - J2 侧长段连杆：`270.98076211 mm`
  - J3 侧短段连杆：`124.55 mm`
  - 两段包含角：`150°`
  - J2-J3 主弦只作为参考线，不作为限位角对象
- 三个正常工作方向 `Y+ / X+ / X-` 都按“侧向观察为凸型”求解。
- 参与限位和切换判定的是长段连杆与 XOY 平面的夹角 `alpha`，不是 J2-J3 主弦角。

### 限位与安全约束

- 长段连杆角工作限位：
  - `-45° <= alpha <= +90°`
- yaw 方向切换安全条件：
  - 切换 yaw 方向时，当前长段连杆角必须 `alpha > 70°`
  - 逆解过程检查该条件，并返回 `YAW_SWITCH_UNSAFE`
  - 后续运动路径规划也必须再次检查该条件
- 逆解失败时返回错误，不自动夹紧目标。
- 建议错误原因包括：
  - `BAD_DIRECTION`
  - `UNSUPPORTED_STATE`
  - `HEIGHT_UNREACHABLE`
  - `LONG_LINK_LIMIT`
  - `YAW_SWITCH_UNSAFE`

### 工具状态表

- 工具几何状态采用表驱动设计。
- 表项至少包含：
  - 工具作用点局部偏置
  - J4/工具姿态约束
  - 该状态是否允许参与 IK
- 未配置的工具状态返回 `UNSUPPORTED_STATE`。
- 工具开启/关闭、吸盘/夹爪动作不属于 IK，本阶段只保留几何姿态入口。

## 接口边界

- 本阶段不修改现有 `ARM_SET_TARGET/TOOL_SET_MODE` USB wire shape。
- 不同步变更 USB/上位机命令为工具三维坐标。
- 当前 4-float 命令可继续保持兼容，用于旧行为或临时调试。
- 需要新的工具控制链来承载更多数据，包括：
  - 工具对象
  - 工具姿态
  - 工具位置
  - 工具开启/关闭
  - 工具状态回传
- 新工具控制链后续单独计划，不在本逆解实现中混入。

## 运动路径规划（待补充）

- 当前只记录已确认约束；插补方式、速度规划、加减速约束、避障/避限策略后续补充。
- 运动路径规划必须以逆解安全为前提，所有路径点都要满足逆解方向、长段连杆角和 yaw 切换安全约束。

### 启动路径

- 机械臂启动时必须先从电机零位转动到 `Y+` 工作空间。
- 从电机零位转到 `Y+` 工作空间期间，坐标系 4 朝向不变，保持上电初始状态朝向。
- 上电初始状态下 `+Z4` 竖直向下。

### 工具姿态

- 使用工具前，需要先完成工具姿态设定。
- 工具姿态只能在上电初始坐标系 4 姿态基础上，绕 `+X0` 方向的 roll 轴旋转。
- 工具 roll 姿态范围：
  - `-pi/2 <= tool_roll <= +pi/2`
- 工具姿态设定完成后，机械臂改变位置时必须维持该工具姿态。
- “维持工具姿态”指在当前 yaw 工作平面内保持该姿态。
- 所有工具姿态坐标轴描述均以 `YOZ` 平面观测为基准；当机械臂运动到 `X+ / X-` 工作平面时，`Y0+ / Y0-` 需要等效处理为当前工作平面的平面正/反方向，`Z0-` 保持竖直向下。
- 夹爪新增三个运动姿态：
  - `GRIPPER_GZ_Y_POS`：`GZ+` 与 `Y0+` 同向，夹爪向上，内部 `phi=-pi/2`。
  - `GRIPPER_GZ_Y_NEG`：`GZ+` 与 `Y0-` 同向，夹爪向下，内部 `phi=+pi/2`。
  - `GRIPPER_GZ_Z_NEG`：`GZ+` 竖直向下，夹爪水平向前，内部 `phi=pi`。
- 夹爪上/下运动姿态需要遵循一来一回：一次使用 `GZ_Y_POS`，下一次使用 `GZ_Y_NEG`，再下一次切回，避免 J3 同向连续旋转造成缠线。

### 工作平面切换

- yaw 工作方向切换时，底盘朝向不改变。
- 如果需要切换 `Y+ / X+ / X-` 工作平面，需要等效切换：
  - 保持工具姿态语义不变。
  - 同时旋转 yaw 轴到目标工作平面。
- 已设置工具姿态后切换工作平面时，不能先丢失工具姿态。
- yaw 方向切换前，必须在保持当前工具姿态的情况下，到达安全姿态：
  - `alpha > 70°`
- 满足 `alpha > 70°` 后，才允许切换 yaw 方向。

## Test Plan

- 方向选择：
  - 覆盖 `Y+`
  - 覆盖 `X+`
  - 覆盖 `X-`
  - 覆盖 `-Y` 且 `x>0`
  - 覆盖 `-Y` 且 `x<0`
  - 覆盖 `-Y` 且 `x≈0`
- 几何一致性：
  - 解算模型零位下 J2-J3 转动关节连线竖直。
  - 解算模型零位下 J4 与 J0 平行。
- 长段限位：
  - `alpha=-45°`
  - `alpha=0°`
  - `alpha=70°`
  - `alpha=90°`
  - 低于 `-45°` 或高于 `90°` 时返回错误，不自动夹紧。
- yaw 切换：
  - 方向变化且 `alpha<=70°` 时返回 `YAW_SWITCH_UNSAFE`。
  - 方向变化且 `alpha>70°` 时允许输出目标方向。
- 工具状态：
  - 未配置状态返回 `UNSUPPORTED_STATE`。
  - 已配置状态能正确扣除工具作用点 z 偏置。
  - 夹爪 `GZ_Y_POS / GZ_Y_NEG` 两个运动姿态在成功命令后交替实际执行，`GZ_Z_NEG` 水平向前姿态固定执行。
- 回归：
  - 旧 USB 命令不破坏。
  - 旧状态包仍可回传 theta、工具世界 z、高度误差。

## Assumptions

- 逆解失败时返回错误，不自动夹紧目标。
- 本文档当前只完整覆盖逆解算；运动路径规划后续继续补充。
- 电机输出轴方向、减速比、电机零位偏置不进入 IK 输出，只在后续电机映射层使用。
- 当前工具状态表已包含 S1/S2 使用姿态、夹爪使用姿态、夹爪 GZ 上/下/水平向前姿态；工具开启/关闭语义仍由后续工具控制链处理。
